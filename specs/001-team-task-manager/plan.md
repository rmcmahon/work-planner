## Summary

**Primary Requirement**: Build a task management dashboard that displays tasks prioritized by user-defined criteria, supports drag-and-drop reordering and subtask relationships, and enforces role-based access control (viewer, worker, admin).

**Technical Approach**: Deliver a minimal full-stack prototype with a Python/FastAPI backend (REST API, auth, task CRUD, role enforcement) and a React frontend (single-page app, dashboard, filters, drag-and-drop). Use SQLite for initial persistence to avoid external dependencies. Include comprehensive unit and integration tests for auth, access control, and task ordering logic.

## Technical Context

**Language/Version**: Python 3.11 (backend), JavaScript/TypeScript (frontend with React 18)  
**Primary Dependencies**: FastAPI, SQLAlchemy, React, react-beautiful-dnd (or react-dnd for drag-and-drop)  
**Storage**: SQLite (initial; upgradeable to PostgreSQL)  
**Testing**: pytest (backend), Jest + React Testing Library (frontend)  
**Target Platform**: Web (server + browser; responsive design for desktop)  
**Project Type**: Web application (backend + frontend)  
**Performance Goals**: Dashboard load <1 second for 500 tasks; drag-drop reorder feedback within 300ms client-side  
**Constraints**: No external auth services (username/password only); no real-time sync in initial version (last-write-wins)  
**Scale/Scope**: MVP scope — 3 user roles, 1 dashboard view, basic CRUD, admin page for user management
